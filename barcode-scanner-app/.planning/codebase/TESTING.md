# Testing Strategy - BillItUp

## Current State
- **Unit Testing**: Limited.
- **E2E Testing**: No specialized framework configured (e.g., Playwright).
- **Manual Verification**: Primary method for verifying native functionality (Camera, Scanning).

## Planned Strategy
- **Vitest**: Recommended for unit testing Vite-based projects.
- **Capacitor Device Preview**: For testing native API integrations.
